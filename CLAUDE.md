# Sito's Estacionamentos — landing page

## Contexto via grafo (graphify)

Este projeto tem um grafo de conhecimento em `graphify-out/` (`graph.json`, `GRAPH_REPORT.md`, `graph.html`).

- Antes de explorar o código para entender estrutura, relações ou onde algo fica, consulte o grafo primeiro:
  `graphify query "<pergunta>"` (ou `graphify path "A" "B"` / `graphify explain "X"`).
- Só depois leia os arquivos que o grafo indicar — não varra o projeto inteiro.
- Para editar código, sempre leia o arquivo real antes; o grafo é mapa, não fonte de verdade.
- Depois de mudanças grandes, atualize o grafo com `/graphify . --update`.
- A fonte única de verdade de HTML/CSS/JS é `docs/CONTRATO.md`.
